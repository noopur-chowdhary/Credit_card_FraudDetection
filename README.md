# Credit_card_FraudDetection
Credit_card_FraudDetection

In the popular credit-card fraud dataset:

V1 to V28 are principal components

They come from PCA (Principal Component Analysis)

The original features were removed for privacy


Model does NOT need human-interpretable meaning
✅ Model needs statistical separability

Think of PCA features as coordinates in a high-dimensional space.

Fraud and normal transactions occupy different regions in that space.
